# CLI чат з персистентною пам'яттю

## Коли використовувати
Коли треба інтерактивний чат, що зберігає історію між запусками.

## Промпт

Створи Python-скрипт [filename].py — інтерактивний CLI чат з Claude.

Вимоги:
- Завантажити ANTHROPIC_API_KEY з .env
- Модель claude-sonnet-4-5
- Безкінечний цикл while True
  - input("Ти: ")
  - exit/quit виходить з повідомленням "Бувай!"
  - Інакше додаємо повідомлення в messages, викликаємо API, виводимо відповідь
- max_tokens: 1024
- system prompt: "[твій system prompt]"
- Завантаження історії з [filename]_history.json при старті
- Збереження після кожної відповіді і при виході
- UTF-8 кодування для української

## Результат
Робочий чат-бот з пам'яттю між сесіями, ~50 рядків коду.
