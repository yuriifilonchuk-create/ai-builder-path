# Перший AI-скрипт з Claude API

## Коли використовувати
Коли треба швидкий PoC скрипт, що звертається до Claude API.

## Промпт

Створи Python-скрипт для файлу [filename].py. Він має:
- Завантажити ANTHROPIC_API_KEY з файлу .env через python-dotenv
- Використати бібліотеку anthropic для звернення до моделі claude-sonnet-4-5
- Надіслати запит: [твій промпт]
- Вивести відповідь у термінал
- max_tokens: 1024
- Type hints обов'язкові

## Результат
Робочий скрипт ~25 рядків з error handling для відсутнього API key.
