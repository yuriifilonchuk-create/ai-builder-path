# Sliding window для контролю токенів

## Коли використовувати
Додати до існуючого чат-бота обмеження довжини історії, що відправляється в API. Захист від token blow-ups.

## Промпт

В файлі [filename].py додай sliding window для messages:
- Константа MAX_HISTORY = 10 (після імпортів)
- Після кожного додавання повідомлення в messages — обрізаємо до останніх MAX_HISTORY елементів через messages = messages[-MAX_HISTORY:]
- Перед кожним запитом виводимо в термінал поточний розмір історії: print(f"[Історія: {len(messages)}/{MAX_HISTORY}]")
- У JSON-файл зберігаємо повну історію (без обрізання), в API відправляємо тільки урізану

Не змінюй system_prompt і обробку exit/quit.

## Результат
Захист від необмеженого росту контексту. Рахунок API не вибухає.
